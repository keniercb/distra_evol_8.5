Figura 1. Interfaz y acciones de la funcionalidad Actividades.

Nota: Existen cuatro niveles: Grupo de la actividad (GA), Sub-grupo de la actividad (SA), Pre-actividad (PA) y Actividad (A). 
Las diferentes opciones que conforman la figura anterior permiten:

  1. Adicionar actividad , ver Adicionar actividad , esta acción permite adicionar actividad del nivel GA. Se puede acceder a esta funcionalidad con las teclas (Alt + I).
  2. Modificar una actividad previamente seleccionada en el listado. Una vez seleccionada la actividad y presionada la opción Modificar de la interfaz, el sistema le mostrará la interfaz con los datos cargados, posibilitando que se modifiquen los datos que se requieran. Se puede acceder a esta funcionalidad seleccionando la actividad y oprimiendo las teclas (Alt + M). El procedimiento del llenado de los datos y selección de los botones de la interfaz Modificar actividad es muy similar al descrito en el Adicionar actividad y en elAdicionar nivel inferior, este último para el caso que la actividad seleccionada sea una actividad con nivel de Actividad (A). Para modificar una actividad se debe comprobar que esta no esté aprobada, pues en caso de que lo esté no se podrá realizar esta acción.
  3. Eliminar una actividad previamente seleccionada en el listado. Esta acción permite eliminar la(s) actividad(es) deseada(s), una vez seleccionada(s) se procede a seleccionar la opción Eliminar de la interfaz, automáticamente se mostrará un mensaje de confirmación, que se puede Aceptar o Cancelar según sea el caso, de presionar la opción Aceptar el sistema le mostrará un mensaje de información sobre el éxito de la operación realizada, quedando eliminada(s) la(s) actividad(es) seleccionada(s), si cancela el mensaje de confirmación, el sistema permanece en la interfaz principal y no elimina la(s) actividad(es). Se puede realizar esta operación seleccionando una actividad en el listado y oprimiendo la tecla (Delete). La actividad seleccionada debe estar desaprobado para poder eliminarla.
  4. Aprobación, inicialmente este botón estará deshabilitado hasta tanto no se haya seleccionado una actividad que esté desaprobada o esté aprobada por el Órgano Demandante y la entidad rectora pretenda dar su nivel de aprobación. Para realizar esta acción se puede seleccionar la actividad deseada dando clic sobre ella y desplegando la opción Aprobación puede seleccionar el botón Aprobar o Desaprobar para cualquiera que sea el caso el sistema mostrará un mensaje de confirmación que puede aceptar o cancelar según desee. Si presiona el botón Aceptar el sistema mostrará un mensaje de información notificando que se realizó la operación con éxito, si presiona el botón Cancelar el sistema cancela la acción.
  5. Exportar, ver Exportar, esta acción permite exportar actividades, actividades con norma, actividades con reglas y actividades con salidas.
  6. Realizar acciones en el Almacén de datos. Se pueden realizar dos acciones Cierre y Actualizar, en ambos casos el sistema mostrará un mensaje de información notificando que se realizó la operación con existo.
  7. Seleccionar los niveles (Grupo de la actividad, Sub-grupo de la actividad, Pre-actividad y Actividad). Si se selecciona un nivel el sistema muestra las actividades que se encuentran en ese nivel en el panel de la interfaz principal.
  8. Seleccionar la especialidad. El sistema muestra las actividades que tiene la especialidad seleccionada.
  9. Gestionar actividades y normas, ver Gestionar actividades y normas.
  10. Gestionar actividades y reglas, ver Gestionar actividades y reglas.
  11. Gestionar salidas, ver Gestionar salidas.
Adicionar actividad  

Para adicionar una actividad del nivel GA el procedimiento es el siguiente: Se selecciona la opción Adicionar que se encuentra en la barra de acciones de la interfaz, ver opción (1) de la figura 1. Inmediatamente aparecerá una ventana donde se podrán especificar los datos relacionados con la actividad que se desea adicionar en el nivel GA, ver figura 2.


Figura 2. Interfaz Adicionar actividad.

Las diferentes opciones que conforman la figura anterior permiten:

  1. Ver el formato que muestra por defecto “Actividades”.
  2. Ver el nivel que indica el nivel donde se va a adicionar la actividad.
  3. Ver la cantidad de dígitos que puede presentar el código al nivel donde se pretende insertar el dato.
  4. Ver la especialidad en la que se encuentra autenticado el usuario.
  5. Introducir la denominación de la actividad que desea insertar.
  6. Mostrar la conformación del código hasta el nivel anterior creado, en caso de ser el primer nivel (GA) muestra el código correspondiente a la especialidad donde se autenticó el usuario.
  7. Introducir el código de la actividad que desea insertar en correspondencia con la cantidad de dígitos mostrados en el campo dígitos.
  8. Introducir una breve descripción de la actividad. Este dato no es obligatorio.
  9. Cancelar las acciones y salir de la interfaz sin guardar los datos.
  10. Guardar los datos y limpiar los campos de la interfaz, permitiendo adicionar otra actividad.
  11. Adicionar los datos de la actividad al listado y cerrar la interfaz.

Validación de los campos:

  • Los campos código y denominación  son obligatorios, en caso de dejar estos campos vacíos el sistema debe mostrar un mensaje en el mismo campo.  Si se acepta con campos en rojo, el sistema mostrará un mensaje de información notificando que existen campos obligatorios vacíos o incorrectos.
  • No se permite adicionar una actividad con un  mismo código. Si esto ocurre el sistema debe mostrar un mensaje de error.
  • El campo código solo acepta números hasta 2 o 3 dígitos (en dependencia del nivel que se esté adicionando la actividad), en caso contrario se debe mostrar el siguiente mensaje en el mismo campo: si sobrepasa la cantidad establecida se mostrará un mensaje de error en el mismo campo, si se introduce letras o algún carácter especialse debe mostrar un mensaje de error.
  • El campo denominación acepta letras, y los caracteres especiales (/ _ y -) y números hasta 255, si sobrepasa la cantidad establecida se debe mostrar un mensaje en el mismo campo, si se introduce algún carácter especial se debe mostrar un mensaje de error.
  • El campo descripción acepta letras, números y caracteres especiales sin límites.

Nota: El código de la actividad se representa solamente por números y la cantidad de caracteres que pueden ingresarse varía en dependencia del nivel de la misma. Esta cantidad se comporta de forma siguiente:

  • Grupo de la actividad (GA)…..2 dígitos.
  • Subgrupo de la actividad (SA)…..2 dígitos.
  • Pre actividad (PA)…..2 dígitos.
  • Actividad (A)…..3 dígitos.

Una vez adicionada una actividad en el sistema se pueden realizar las siguientes acciones sobre ella:

  • Seleccione la actividad del nivel inmediato superior a la que pertenece la actividad que desea adicionar, o sea, seleccione la actividad de la cual se deriva dicha actividad. Haga un clic secundario sobre la actividad seleccionada y aparecerán las siguientes opciones: ver figura 3.


Figura 3. Interfaz Actividades\Acciones que se pueden realizar sobre una actividad.

Las diferentes opciones que conforman la Figura anterior permiten:

  1. Adicionar nivel inferior, ver Adicionar nivel inferior, esta acción es similar a la acción de Adicionar actividad, para ejecutar esta operación el sistema le mostrará una interfaz con los datos que debe llenar. Debe tener en cuenta que para adicionar un nivel inferior se debe verificar que la actividad de la cual se deriva no se encuentre Aprobada, si se encuentra aprobada, no se podrá realizar la acción y aparecerá un mensaje de error.  Se puede realizar esta operación de manera rápida seleccionando la actividad y presionando la combinación de las teclas (Alt + F).
  2. Duplicar actividad, el procedimiento del llenado de los campos es muy similar al descrito en el Adicionar actividad. Esta funcionalidad tiene como objetivo que el usuario no tenga que repetir los pasos para adicionar una nueva actividad, sobre todo si los datos de la nueva actividad son similares a la ya existente. Esta acción permite registrar una nueva actividad en el sistema, a partir de una que ya está creada, solamente modificando algunos de sus datos. Se puede realizar esta acción de manera rápida seleccionando la actividad y presionando la combinación de las teclas (Ctrl + Alt + D).
  3. Adicionar normas, ver Adicionar normas. Se debe desglosar el árbol de entidades hasta el último nivel y se selecciona una actividad previamente insertada que se encuentre Desaprobada. Se puede realizar esta acción de manera rápida seleccionando la actividad y presionando la combinación de las teclas (Alt + O).
  4. Asociar a plan, ver Asociar a plan. Se debe desglosar el árbol de entidades hasta el último nivel y se selecciona una actividad previamente insertada que se encuentre Desaprobada. Se puede realizar esta acción de manera rápida seleccionando la actividad y presionando la combinación de las teclas (Alt + P).
  5. Activar actividad, debe seleccionar la actividad que quiere activar y presionar la opción Activar el sistema mostrará un mensaje de confirmación, que puede Aceptar o Cancelar según desee. Si presiona el botón Aceptar el sistema mostrará un mensaje de información notificando que se activó la(s) actividad(es) satisfactoriamente, si presiona el botón Cancelar se cancela la acción. Para activar una actividad la misma debe estar en estado desaprobada y desactivada. Se puede realizar esta acción de manera rápida seleccionando la actividad y presionando la combinación de las teclas (Alt + X).
  6. Desactivar actividad, debe seleccionar la actividad que quiere desactivar y presionar la opción Desactivar el sistema mostrará un mensaje de confirmación, que puede Aceptar o Cancelar según desee. Si presiona el botón Aceptar el sistema mostrará un mensaje de información notificando que se desactivó la(s) actividad(es) satisfactoriamente, si presiona el botón Cancelar se cancela la acción. Para activar una actividad la misma debe estar en estado activada. Se puede realizar esta acción de manera rápida seleccionando la actividad y presionando la combinación de las teclas (Alt + K).

Normas

Al seleccionar el botón Normas, opción (9) de la figura 1, se ejecuta una acción donde se muestran  las normas que pertenecen a la actividad seleccionada. Para Adicionar norma de consumo a una actividad esta debe encontrarse en el último nivel de conformación del código, o sea, en Actividad. Solo puede adicionarse una norma de consumo a una actividad que esté Desaprobada. Si intenta adicionar norma a una actividad en estado de Aprobada, el sistema emitirá un mensaje de error indicando que la actividad está aprobada.
Se debe presionar clic derecho sobre la actividad a la que se desea adicionar una norma, se despliega un submenú como el que se muestra en la figura 3 y  se selecciona con un clic la opción Adicionar norma. Automáticamente el sistema muestra la interfaz Adicionar normas, ver figura 7.


Figura 7. Interfaz Adicionar normas.

Las diferentes opciones que conforman la figura anterior permiten:

  1. Seleccionar los indicadores a insertar en la Norma de consumo, puede realizar la selección múltiple de los indicadores que se muestran.
  2. Cancelar las acciones y salir de la interfaz sin guardar los datos.
  3. Guardar los datos y limpiar los campos de la interfaz, permitiendo adicionar otro indicador.
  4. Adicionar los indicadores y cerrar la interfaz.

Una vez adicionado las normas el sistema permite mostrar las normas existentes en una ventana nueva que aparece en la parte inferior de la interfaz, al seleccionar la actividad que contiene al menos una norma, ver figura 8.


Figura 8. Interfaz Normas de una actividad.

En esta nueva interfaz se pueden modificar datos de las columnas Norma y Base, de la norma elegida, estos valores deberán ser de tipo numérico.
Una vez que los datos han sido modificados satisfactoriamente, se podrá almacenar en el sistema la nueva información con solo presionar la tecla Enter del teclado. Si la información es incorrecta el sistema señala el dato erróneo marcando la intersección en rojo.
En la parte inferior de esta ventana, se muestra el importe total de la norma para la actividad seleccionada, siendo el resultado de la suma de los importes de los indicadores contenidos en ella.

Si presiona el botón Aceptar del mensaje de confirmación el sistema mostrará un mensaje de información notificando que se eliminó satisfactoriamente la norma, si presiona el botón Cancelar se cancela la acción.

Reglas
Reglas es un proceso en el que el usuario puede relacionar un indicador existente en una norma de consumo con otras actividades que pueden ejecutarse predeterminadamente a partir de dar un Nivel de Actividad a la actividad seleccionada. Al dar Nivel de Actividad a una Actividad que contiene Reglas se ejecuta una función matemática que calcula y muestra automáticamente los Niveles de Actividad que corresponden a las actividades asociadas por este método.

  1. A partir de la selección de un indicador contenido en una norma, se realiza clic secundario para desplegar el submenú representado en la figura 9.
  2. Se selecciona la acción Adicionar regla y se despliega una ventana en la cual se muestra el resto de las actividades.
  3. Seleccionamos la actividad con la cual se quiere establecer la relación.
  4. Se introducen los datos correspondientes en Valor de Control y Nivel Base, estableciendo el valor de relación existente entre nivel de actividad igual a uno de la norma donde se encuentra el indicador por el cual establecemos la Regla y la actividad recientemente seleccionada. El Valor de control y el Nivel base deberán ser datos de tipo numérico y el valor del Nivel base debe ser mayor o igual que 1.
  5. Se presiona el botón Aceptar, Aplicar o Cancelar. Si pulsa el botón Aceptar: Se adiciona la Regla y se cierra la ventana, quedando actualizado el listado existente en la ventana Reglas.  Se muestra un mensaje informando que se ha realizado la operación satisfactoriamente, pulse el botón Aceptar del mensaje. Si pulsa el botón Aplicar: se adiciona la regla, y se queda la ventana disponible para adicionar una nueva. Si pulsa el botón Cancelar: No se adiciona la Regla y se cierra la ventana actual.

El sistema también muestra las reglas existentes en una ventana nueva que aparece en la parte inferior de la interfaz, esta ventana se encuentra en la misma posición en que se encuentra la primera ventana donde se halla la norma seleccionada, ver figura 11.
