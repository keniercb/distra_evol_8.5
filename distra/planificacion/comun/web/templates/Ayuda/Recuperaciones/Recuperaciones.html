--Recuperaciones--

Para acceder a esta funcionalidad se debe seguir la siguiente ruta: Inicio\Planificación material\Recuperaciones\Recuperaciones. Luego de acceder a la funcionalidad Recuperaciones el sistema mostrará la siguiente interfaz, ver Figura 1.

Figura 1. Interfaz Recuperaciones.

Nota: para obtener los reportes se debe seleccionar el Reporte que desea obtener, en dependencia del reporte que se seleccione se mostrará una interfaz con los filtros para obtener la información y visualizar el reporte.

Si se selecciona el reporte de:

  • Resumen del plan por Vía de adquisición. Una vez seleccionada la misma, el sistema le mostrará la siguiente interfaz, ver figura 2.


Figura 2. Interfaz Recuperaciones\Vía de adquisición.

Las diferentes opciones que conforman la figura anterior permiten:

  1. Seleccionar el ejercicio.
  2. Seleccionar el nivel del código, este puede ser Genérico, Subgenérico, Especifico y Surtido.
  3. Seleccionar el órgano demandante, el sistema mostrará una interfaz que permite seleccionar uno o varios órganos demandantes, ver Figura 3.
  4. Introducir la clasificación del plan.
  5. Seleccionar uno o varios Plan.
  6. Seleccionar uno o varios centros de balance.
  7. Seleccionar una o varias vías de adquisición.
  8. Introducir el código del reporte.
  9. Introducir el número de piezas.
  10. Introducir la denominación del reporte.
  11. Marcar si quieres o no mostrar los indicadores en el reporte.
  12. Seleccionar el formato del reporte.
  13. Seleccionar la orientación de la hoja, este puede ser vertical u horizontal.
  14. Seleccionar el tipo de hoja a imprimir.
  15. Cerrar ventana sin guardar los datos.
  16. Guardar datos y cerrar ventana.


    Figura 3. Interfaz Órgano demandante

Las diferentes opciones que conforman la figura anterior permiten:

  1. Seleccionar el(los) órganos demandantes que desea incorporar al campo Órgano demandante para efectuar la recuperación.
  2. Cerrar la ventana sin guardar los cambios.
  3. Guardar los datos y cerrar la ventana.


Figura 4. Interfaz Clasificación del plan.

Las diferentes opciones que conforman la figura anterior permiten:

  1. Desglosar el árbol de clasificaciones y seleccionar la clasificación del plan que desea incorporar al campo Clasificación del plan para efectuar la recuperación.
  2. Cerrar la ventana sin guardar los cambios.
  3. Guardar los datos y cerrar la ventana.
  • Resumen de productos por OACE. Una vez seleccionada esta opción el sistema le mostrará la siguiente interfaz, ver figura 5.

Figura 5. Interfaz Recuperaciones\Productos por OACE.

  2. Seleccionar el nivel del código, este puede ser Genérico, Subgenérico, Especifico y Surtido.

  7. Seleccionar una o varias vías de adquisición.
  8. Seleccionar uno o varios sectores ramas de los listados a desglosar el campo.
  9. Introducir el número de piezas.
  10. Introducir la denominación del reporte.
  11. Introducir el código del reporte.
  12. Marcar en caso que se deseen mostrar los indicadores en el reporte.
  13. Seleccionar el formato del reporte.

    • Recuperación para los datos del balance. Una vez seleccionada esta opción el sistema le mostrará la siguiente interfaz. Ver figura 9.


    Figura 9. Recuperaciones/Datos del balance.

    Las diferentes opciones que conforman la figura anterior permiten:

    1. Seleccionar el ejercicio.
    2. Seleccionar el comportamiento. Estos pueden ser Centro de balance u Órgano demandante.
    3. Seleccionar un centro de balance. Este campo se habilitará si selecciona el comportamiento Centro de balance.
    4. Seleccionar un órgano demandante. Este campo se habilitará una vez seleccionado un Centro de balance.
    5. Seleccionar una entidad. Una vez invocado este campo el sistema le mostrará una interfaz que le permitirá seleccionar la entidad deseada. Ver figura 10. Este campo se habilitará una vez seleccionado un comportamiento de tipo Órgano demandante.
    6. Seleccionar un Plan. Este campo se le habilitará una vez seleccionado un órgano demandante, (para el caso que seleccione un Comportamiento de tipo Órgano demandante) o una entidad, (para el caso que seleccione un Comportamiento de tipo Centro de balance).
    7. Marcar si desea balancear o no los indicadores en el reporte. Este campo se habilitará si selecciona el comportamiento “Centro de balance” y selecciona uno de los centros de balance de los listados al desglosar el campo Centro de balance.
    8. Marcar si quieres o no mostrar los indicadores en el reporte.
    9. Seleccionar el formato del reporte.
    10. Seleccionar la orientación de la hoja, este puede ser vertical u horizontal.
    11. Seleccionar el tipo de hoja a imprimir.
    12. Cerrar la ventana sin guardar los datos.
    13. Guardar los datos y cerrar la ventana.

    Nota: Para realizar algún tipo de recuperaciones hay que tener en cuenta que todos los datos de cada una de las interfaces anteriores  son obligatorios, en caso de dejar alguno de los campos vacios el sistema mostrará un mensaje de error en el mismo campo.
