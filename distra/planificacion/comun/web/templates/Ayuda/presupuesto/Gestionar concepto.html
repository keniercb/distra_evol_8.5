--Gestionar concepto--

Para llegar a la funcionalidad se puede acceder a través de la opción Inicio\Planificación material\Presupuesto\Gestionar concepto. El sistema le mostrará la interfaz que aparece en la Figura 1.

Figura 1. Interfaz Gestionar concepto.

Las diferentes opciones que conforman la Figura anterior permiten:

  1. Adicionar concepto, Ver figura 2, esta acción permite adicionar conceptos, cuando se presione el botón Aceptar o Aplicar de la interfaz el sistema mostrará un mensaje de información notificando que se adicionó el concepto. Se puede acceder a esta funcionalidad con las teclas (Alt + I).
  2. Modificar concepto, esta acción permite modificar conceptos. Se puede acceder a esta funcionalidad seleccionando un concepto y oprimiendo las teclas (Alt + M). Si al modificar el concepto se introduce uno que ya existe, el sistema mostrará un mensaje de error.
  3. Eliminar concepto, esta acción permite eliminar conceptos. Se puede realizar esta operación seleccionando el concepto en el listado y oprimiendo la tecla (Del). Si se selecciona un concepto que está siendo usado, el sistema mostrará un mensaje de error.
  4. Mostrar ayuda de la funcionalidad, Se puede realizar esta acción de manera rápida con la combinación de las teclas (Alt + H).
  5. Mostrar el listado de los conceptos existentes en el sistema.

Adicionar concepto

Se presiona el botón Adicionar de la interfaz, ver figura 1. Inmediatamente aparecerá una ventana donde se podrán especificar los datos relacionados con el concepto que se desea adicionar, ver figura 2.

Figura 2. Interfaz Gestionar concepto.

Las diferentes opciones que conforman la figura anterior permiten:

  1. Introducir la denominación del concepto.
  2. Seleccionar el color que quiere que tenga el concepto.
  3. Introducir la descripción del concepto.
  4. Cerrar la ventana, se muestra un mensaje de información sobre el éxito de la operación realizada, se acepta el mensaje y queda actualizado el listado existente en la interfaz principal.
  5. Mostrar un mensaje de información sobre el éxito de la operación realizada, se acepta el mensaje y se permanece en la misma interfaz facilitando la posibilidad de poder adicionar otro concepto.

  6. Cerrar la ventana para adicionar conceptos sin tener en cuenta la posibilidad de haber introducido algún dato en alguno de los campos de la interfaz.

Nota: para adicionar un concepto se debe tener en cuenta las siguientes validaciones:

  • Todos los campos de la interfaz Adicionar concepto son obligatorios en caso de dejar alguno de estos campos en blanco el sistema mostrará un mensaje de error en el mismo campo.
  • El campo denominación solo acepta caracteres alfanuméricos hasta 255 caracteres, si sobrepasa la cantidad establecida se debe mostrar un mensaje de error en el mismo campo. Si se introduce caracteres especiales se debe mostrar un mensaje de error en el mismo campo.
