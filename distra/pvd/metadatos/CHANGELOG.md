# Registro de cambios 
Todos los cambios notables de este proyecto se documentarán en este archivo. 

El formato se basa en [Mantenga un registro de cambios](https://configuracion-ge.prod.xetid.cu/doku.php?id=div:gest_conf:desarrollo:desarrollo:git:git_tags_registro_cambios),
 y este proyecto se adhiere a [Versionado Semántico](https://configuracion-ge.prod.xetid.cu/doku.php?id=div:gest_conf:desarrollo:desarrollo:git:git_tags_nomenclatura).

## [1.7.8] - 2024-08-15
### Reparado
- SC: En Gestionar proyectos, en el botón Documentos / Reporte de Plantilla, solo los órganos internos que contengan cargos.
- En Gestionar proyectos, en el botón Documentos / Reporte de Plantilla: no se visualiza la categoría ocupacional Directivo Ejecutivo.

## [1.1.7] - 2023/10/13
### Reparado
- Se incluye la carpeta que se emplea para guardar los organigramas generados por el sistema.

## [1.1.6] - 2023/08/25
### Reparado
- Reimplementar la funcionalidad para incorporar en el adicionar estructura el campo Código NIRC. 
- Script para modificar el tipo de datos del Código NIRC a varchar.

## [1.1.5] - 2023/08/24
### Reparado
- Reimplementar el metodo para incorporar en el adicionar estructura el campo Código NIRC.

## [1.1.4] - 2023/01/24
### Reparado
- Incorporar en el adicionar estructura el campo Código NIRC.

## [1.1.3] - 2022/10/13
### Reparado
 - No permitir eliminar y mostrar un mensaje de alerta cuando se intenta eliminar una estructura que está siendo usada.

## [1.1.2] - 2022/06/22
### Reparado
- Se establecen valores por defecto en la gestión de los cargos.
- Correcciones en el reporte de pantilla
- Correcciones en el reporte de cambios por proyectos.
- Correcciones en la búsqueda de dominios.
- Actualización de la validación del código de la entidad.

## [1.1.0] - 2021/11/11
### Agregado
- Historial de reporte de plantilla.
- Historial de cambios por proyectos.
- Gestión de nuevos atributos del cargo: alias, principal y jefe de brigada.
- Gestión de nuevo atributo de la entidad: alias.

## [1.0.0] - 2021/10/29
### Agregado
- Codigo fuente del proyecto para comenzar las entregas por tags.
