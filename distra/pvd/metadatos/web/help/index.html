El Subsistema de gestión organizacional tiene como objetivo principal crear estructuras organizativas y/o jerárquicas de una o varias unidades organizativas mediante propuestas de cambios y ajustes organizacionales, además de la creación de áreas de responsabilidad o estructuras no formales sobre la subordinación oficial de una o varias unidades organizativas u organizaciones.

 

El sistema de gestión organizacional está dividido en cuatro funcionalidades fundamentales, las cuales se interrelacionan creando una dependencia lógica entre las mismas:

Configuración: permite la configuración de los conceptos a emplear en la estructura organizativa y la jerarquía entre ellos, al mismo tiempo de gestionar los nomencladores, base de conocimiento para la realización de ajustes organizacionales; que permiten clasificar los valores utilizados dentro de las entidades, además de las restricciones entre usuarios y conceptos determinados para los permisos de trabajo en la gestión estructural del contenido.

Gestionar proyecto: permite que los usuarios con permisos gestionen los proyectos según las necesidades de las estructuras organizativas de la entidad a partir de la configuración jerárquica registrada por el administrador en el componente de configuración. Además, admite la modificación jerárquica de la información asociada a la estructura organizativa a partir de un concepto de subordinación.

Gestionar estructura: permite crear la estructura organizativa orgánica (real) a partir de la configuración previa del negocio y utilizando si se requiere los nomencladores previamente definidos.

Reporte gráfico: permite gestionar en gráficas, a través de una previa configuración de consulta estructural, el contenido registrado en la entidad así como recuperar las configuraciones previas del usuario.

Esta funcionalidad permite guardar los datos generales y asignar permisos a un concepto determinado, además de gestionar los nomencladores que conforman las estructuras de las diferentes entidades. Para acceder a esta funcionalidad se selecciona la opción Gestión organizacional/ Configuración y el sistema mostrará la interfaz, ver Figura 1.

A continuación se realiza descripción detallada de cada uno de los conceptos a configurar en el sistema:

  • General: concepto que referencia al nodo inicial del árbol organizacional, que permite gestionar aquellos restantes conceptos que podrán ser adicionados, desde el nodo raíz. Debe subordinar órganos rectores, entidades u organizaciones.
  • Órgano: una institución de primer nivel que contiene unidades organizativas. Debe subordinar agrupaciones, entidades u organizaciones.
  • Agrupación: es un concepto utilizado para agrupar o unir de manera lógica estructuras similares, que debe subordinar órganos rectores, entidades u organizaciones.
  • Entidad: representa conceptualmente un objeto físico organizativo, empresa, entidades o institución. A partir de este elemento solo deben subordinarse elementos internos del organismo, órganos internos, agrupaciones internas, estructuras no formales, cargos y medios.
  • Organización: similar al concepto entidad, a diferencia que representa una institución física rectora de otras entidades, o sea una empresa que representa una cadena de empresas. Debe subordinar entidades, órganos internos, agrupaciones internas, estructuras no formales, cargos y medios.
  • Órgano interno: estructura que representa elementos físicos internos a una entidad. Ejemplo: departamentos, direcciones, almacenes u otros. Debe subordinar al menos cargos y medios.
  • Agrupación interna: es un concepto utilizado para agrupar o unir de manera lógica estructuras internas similares, que debe subordinar al menos órganos internos.
  • Cargo civil: Tipo de estructura para representar personal civil. Se diferencia del militar que posee categoría ocupacional. No debe subordinar ningún concepto.
  • Cargo militar: Tipo de estructura para representar personal militar. Se diferencia del civil que posee grado militar No debe subordinar ningún concepto.
  • Estructura no formal: es una organización, grupo, comité que no forma parte de la estructura orgánica sino que sirve para agrupar estructuras o servir de base a otros procesos.
  • Medio: representa los medios básicos asignados a los órganos internos o cargos de necesitarse. No debe subordinar ningún concepto.

En caso que se desee eliminar un elemento que se encuentre en uso en la estructura, el sistema no le permitirá eliminarlo; debe tenerse en cuenta que al seleccionar varios elementos si al menos uno se encuentra en uso, el sistema no lo(s) especificará y no permitirá eliminar ninguno de los seleccionados con anterioridad.

Previamente seleccionado un elemento, se elige por la opción Desactivar de la interfaz. Posteriormente el sistema muestra un mensaje de confirmación, se acepta el mismo y se muestra un mensaje del éxito de la operación realizada mostrándose el elemento con las opciones actual y visible desactivadas y con las opciones Modificar y Eliminar inhabilitadas, lo que quiere decir que el nomenclador va a existir pero no podrá ser utilizado hasta que se presione la opción Activar y viceversa. Si el nomenclador está en uso ninguno de los pasos anteriormente descritos se llevan a cabo y de cancelar el mensaje de confirmación el sistema permanece en la interfaz principal y no desactivará el elemento.

De cancelar el mensaje de confirmación el sistema permanece en la interfaz principal y no activará el elemento.

El Subsistema de gestión organizacional tiene como objetivo principal crear estructuras organizativas y/o jerárquicas de una o varias unidades organizativas mediante propuestas de cambios y ajustes organizacionales, además de la creación de áreas de responsabilidad o estructuras no formales sobre la subordinación oficial de una o varias unidades organizativas u organizaciones.

 

El sistema de gestión organizacional está dividido en cuatro funcionalidades fundamentales, las cuales se interrelacionan creando una dependencia lógica entre las mismas:

Configuración: permite la configuración de los conceptos a emplear en la estructura organizativa y la jerarquía entre ellos, al mismo tiempo de gestionar los nomencladores, base de conocimiento para la realización de ajustes organizacionales; que permiten clasificar los valores utilizados dentro de las entidades, además de las restricciones entre usuarios y conceptos determinados para los permisos de trabajo en la gestión estructural del contenido.

Gestionar proyecto: permite que los usuarios con permisos gestionen los proyectos según las necesidades de las estructuras organizativas de la entidad a partir de la configuración jerárquica registrada por el administrador en el componente de configuración. Además, admite la modificación jerárquica de la información asociada a la estructura organizativa a partir de un concepto de subordinación.

Gestionar estructura: permite crear la estructura organizativa orgánica (real) a partir de la configuración previa del negocio y utilizando si se requiere los nomencladores previamente definidos.

Reporte gráfico: permite gestionar en gráficas, a través de una previa configuración de consulta estructural, el contenido registrado en la entidad así como recuperar las configuraciones previas del usuario.

De cancelar el mensaje de confirmación el sistema permanece en la interfaz principal y no eliminará la configuración seleccionada.

Al seleccionar la opción Graficar se muestra la representación gráfica de la configuración previamente adicionada por el usuario, ver Figura 1.

Figura 1. Interfaz de la Representación gráfica de la configuración

En la figura anterior se muestra a la izquierda de la interfaz el listado de estructuras, donde el usuario puede seleccionar las que desee que se grafiquen a la derecha de la interfaz, en caso que desee ver la representación gráfica en la pantalla completa al usuario debe deslizar el panel hacia la izquierda. Se muestran en el borde superior derecho la configuración en forma de pastel, barras, líneas y curvas que el usuario podrá representar gráficamente. Finalmente el usuario debe presionar el botón Cerrar para volver a la interfaz principal de Reportes.

Una vez que se encuentre en la interfaz principal Reportes gráfico se presiona el botón Buscar, se muestran los datos correspondientes con los criterios de búsquedas previamente introducidos en el sistema, en caso que los mismos no hayan sido introducidos con anterioridad se mostrará un mensaje de error. En caso que se introduzca una configuración que no coincida con las del listado se muestra un mensaje de información.

Una vez que se encuentre en la interfaz principal Reportes se presiona el botón Limpiar, en caso que existan datos en los campos de criterios de búsqueda se limpiarán los mismos y se mostrará la lista de configuraciones actualizada.
