Ayuda del componente Gestor de paquetes

Versión: 2.0

Fecha de liberación: 13/3/2015

Descripción:

Automatiza la gestión de instaladores de aplicaciones construidas sobre el marco de trabajo. Provee de una estructura para instalar nuevos componentes al menú que muestra el portal de aplicaciones.

Contiene un panel donde se listan los paquetes adicionados al repositorio activo. El gestor permite adicionar repositorios y paquetes, permitiendo que estos puedan gestionarse mediante las opciones de eliminar paquetes, instalar, desinstalar, reinstalar y actualizar. Además cuenta con las funcionalidades de crear un nuevo paquete, y recertir los cambios realizados en una actualización.

A través del sistema de búsqueda pueden encontrarse los paquetes que se desean gestionar, de los que también es posible conocer el estado, cual es su última versión y la versión instalada. De cada paquete es posible obtener una descripción, que brinda detalles de los paquetes para facilitar la gestión de los mismos.

Gestionar aplicaciones

Al seleccionar la opción Inicio/Herramientas/Panel de controlo/Gestionar aplicaciones se muestra la interfaz Gestionar aplicaciones, que permite instalar, actualizar, reinstalar y desinstalar aplicaciones orientado a un entorno de despliegue, así como gestionar los repositorios donde se encuentran almacenadas estas aplicaciones, ver Figura 1.

Figura 1. Interfaz de Gestionar aplicaciones.

Gestionar repositorio de paquetes

Esta funcionalidad permite adicionar, activar, desactivar, modificar y eliminar los repositorios de paquetes de aplicaciones gestionados por el usuario. Se accede a Inicio/Herramientas/Panel de control/Gestionar aplicaciones y se muestra la interfaz principal Gestionar aplicaciones.

En la interfaz Gestionar aplicaciones, ver Figura 1 se muestra a la izquierda del listado de paquetes, un árbol que contiene los repositorios gestionados por el usuario con los botones de adicionar, modificar y eliminar que permiten la gestión de la información de cada repositorio.

Adicionar repositorio de paquetes

Se accede a Inicio/Herramientas/Panel de control/Gestionar aplicaciones y se muestra la interfaz Gestionar aplicaciones, ver Figura 1 con el árbol de repositorios gestionados por el usuario, en el panel izquierdo. Para adicionar un repositorio a este árbol se deben seguir los pasos siguientes:

  1. Seleccionar la opción Adicionar y aparece la interfaz Adicionar repositorio, ver Figura 2.
  2. Introducir la denominación y dirección URL del repositorio donde se ubicará dicho almacén de paquetes físicos.
  3. Presionar el botón Aceptar de la interfaz Adicionar repositorio.

Al realizar estas acciones se muestra el mensaje de éxito de la operación, ver Figura 3.  Para salir de la interfaz y cancelar la operación se presiona el botón Cancelar.

Figura 2. Interfaz de Adicionar repositorio.

Figura 3. Mensaje de éxito al adicionar un repositorio.

Activar repositorio de paquetes

Esta funcionalidad es la opción que tiene el usuario para ver los paquetes que tienen los repositorios que él desee. Cuando activa un repositorio, la interfaz principal Gestionar aplicaciones, se actualiza y muestra los paquetes de este servidor que se activó. Inicialmente, siempre se encuentra activado, el repositorio local que tiene el usuario, y es donde se van a guardar los paquetes que gestione.

Los repositorios pueden activarse seleccionando los checkbox ubicado a la izquierda de la denominación de cada uno de estos, ver Figura 4.

Figura 4. Interfaz principal Gestionar aplicaciones.

Desactivar repositorio de paquetes

Esta funcionalidad es la opción que tiene el usuario para ver los paquetes que tienen los repositorios que él desee. Cuando desactiva un repositorio, la interfaz principal Gestionar aplicaciones, se actualiza y deja de mostrar los paquetes de este servidor que se desactivó. Inicialmente, siempre se encuentra activado, el repositorio local que tiene el usuario, y es donde se van a guardar los paquetes que gestione.

Los repositorios pueden desactivarse desmarcando los checkbox ubicado a la izquierda de la denominación de cada uno de estos, ver Figura 4.

Modificar repositorio de paquetes

Esta funcionalidad permite modificar un repositorio del árbol de repositorios de paquetes gestionados por el usuario. Para modificar la información de un repositorio, se deben seguir los siguientes pasos:

  1. Seleccionar el repositorio que se desea modificar del árbol de repositorios que muestra la interfaz Gestionar aplicaciones,ver Figura 4.
  2. Realizar los cambios deseados en la información del repositorio que se muestra en la interfaz Modificar repositorio, ver Figura 5.
  3. Presionar el botón Aceptar para guardar los cambios realizados y actualizar la información del repositorio seleccionado.

 

Figura 5. Interfaz de Modificar repositorio.

Eliminar repositorio de paquetes

Para eliminar un repositorio se accede a la interfaz principal Gestionar aplicaciones, ver Figura 4 para la gestión de los mismos, y se sdeben seguir los pasos siguientes:

  1. Seleccionar el repositorio que se desea eliminar del árbol de repositorios.
  2. Presionar el botón Eliminar ubicado encima del árbol.
  3. Presionar el botón Aceptar del mensaje de confirmación mostrado, ver Figura 6.

Figura 6. Mensaje de confirmación de Eliminar repositorio.

Para encontrar el repositorio de forma más rápida, se puede utilizar la barra de búsqueda ubicada encima del listado.

Al eliminar el repositorio se muestra el mensaje de éxito: “El repositorio ha sido eliminado satisfactoriamente.” y se actualiza el listado de repositorios. Luego se actualiza el listado de paquetes en la interfaz principal, eliminando los que pertenecen al repositorio eliminado. Para salir de la interfaz y cancelar las operaciones se presiona el botón Cancelar del mensaje de confirmación.

Instalar paquete

Para instalar un paquete debe seleccionarse del listado que se muestra en la interfaz principal Gestionar aplicaciones, ver Figura 7. Al ejecutar esta acción se aprecia que en la barra de opciones, el botón Desinstalar se encuentra desactivado y en la columna Estado debe indicar “No Instalado”, expresando que el componente no se encuentra instalado, como se muestra en la siguiente figura.

Figura 7. Interfaz Gestionar aplicaciones.

Para instalar un paquete se deben seguir los pasos siguientes:

  1. Seleccionar un paquete del listado que tenga como estado "No instalado".
  2. Presionar el botón Instalar ubicado encima del listado de paquetes mostrado en la interfaz Gestionar aplicaciones (Ver Figura 15).
  3. Verificar los cambios que se aplicarán con la instalación e introducir los datos de la conexión a la base de datos si el paquete a instalar posee base de datos, en la interfaz Instalar paquete, ver Figura 8.
  4. Presionar el botón Aceptar de la interfaz Instalar paquete.

Figura 8. Interfaz de Instalar paquete.

De no tener conexión a una base de datos se desmarca la opción Conexión de base de datos y se desactivará el formulario. Luego de presionar el botón Aceptar aparece el mensaje de éxito de la operación: “Se instaló correctamente la aplicación”.
Una vez instalado el paquete se actualiza su estado en la interfaz principal, se observa que su estado pasa de ser “No instalado” a “Instalado”. También el campo Versión instalada, se actualiza con la versión del paquete instalado.

Reinstalar paquete

En caso de que se desee reinstalar un paquete, se selecciona el paquete en la interfaz principal Gestionar aplicaciones, ver Figura 7 y se observa que el botón Reinstalar se activa, mientras que Instalar se encuentra desactivado. Se presiona la opción Reinstalar y aparece el mensaje de confirmación: “¿Está seguro que desea reinstalar el paquete?”. Se presiona el botón Aceptar y aparece un mensaje de espera del tiempo que demora en reinstalarse el producto. Finalmente se muestra el mensaje de éxito de la operación: “Se ha reinstalado la aplicación correctamente”.

Actualizar paquete

Cuando se realiza una actualización de un paquete se comprueba que su estado sea “Desactualizado”. Al seleccionar el paquete que se desea actualizar, se observa que el botón Instalar se encuentra desactivado y que se activa el botón Actualizar. Para actualizar un paquete se deben seguir los siguientes pasos:

  1. Seleccionar el paquete del listado de paquetes mostrado en la interfaz principal Gestionar aplicaciones, ver Figura 7.
  2. Presionar la opción Actualizar que se muestra encima del listado de paquetes.
  3. Verificar los cambios que se aplicarán con la actualización incluidos los datos de la conexión a la base de datos si el paquete a instalar posee base de datos, en la interfaz Actualizar paquete.
  4. Presionar el botón Aceptar de la interfaz Actualizar paquete.
  5. Presionar el botón Aceptar del mensaje de confirmación.

Revertir actualización

Esta funcionalidad permite revertir los cambios realizados en el sistema luego de haber actualizado un paquete a una versión superior. Esto permite regresar el componente a una versión anterior en caso de que haya ocurrido algún error. Para revertir una actualización se deben seguir los siguientes pasos:

  1. Se selecciona el paquete que recién se actualizó a una versión superior.
  2. Se presiona el botón Revertir actualización en la barra de opciones.
  3. Verificar los cambios que se aplicarán con la operación en la interfaz Revertir actualización.
  4. Presionar el botón Aceptar de la interfaz Revertir actualización.
  5. Presionar el botón Aceptar del mensaje de confirmación mostrado.

Desinstalar paquete

Esta funcionalidad permite desinstalar paquetes que hayan sido instalados en el marco de trabajo. Cuando se desea desinstalar un paquete se aprecia que en la barra de opciones el botón Instalar se encuentra desactivado y que en la columna Estado se indica “Instalado”, expresando que el componente ha sido instalado anteriormente.

Para desinstalar un paquete se debe seguir los siguientes pasos:

  1. Seleccionar del listado el paquete  instalado que se desee desinstalar.
  2. Presionar el botón Desinstalar de la barra de opciones de la interfaz Gestionar aplicaciones, ver Figura 9.
  3. Verificar los cambios que se aplicarán con la desinstalación en la interfaz Desinstalar paquete, ver Figura 10.
  4. Presionar el botón Aceptar de la interfaz Desinstalar paquete.
  5. Presionar el botón Aceptar del mensaje de confirmación mostrado.

 

Figura 9. Interfaz principal Gestionar aplicaciones.

Figura 10. Interfaz de Desinstalar paquete.

Buscar paquete

En la barra de opciones de la interfaz Gestionar aplicaciones se muestran campos de búsqueda, que permite encontrar los paquetes a partir de su nombre o estado. Una vez introducido el nombre del paquete que se desea encontrar o el estado del paquete se presiona el botón Buscar, ver Figura 10, se actualiza el listado de paquetes ubicado debajo de la barra de opciones y se muestra aquel cuyo nombre contiene el introducido o el estado coincida con el seleccionado, ver Figura 10.

Figura 10. Interfaz de Buscar paquete.
