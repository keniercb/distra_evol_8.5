Ayuda del componente Gestor de paquetes

Versión: 1.0

Fecha de liberación: 13/3/2015

 Descripción:

Automatiza la gestión de instaladores de aplicaciones construidas sobre el marco de trabajo. Provee de una estructura para instalar nuevos componentes al menú que muestra el portal de aplicaciones.

Contiene un panel donde se listan los paquetes adicionados al repositorio activo. El gestor permite adicionar repositorios y paquetes, permitiendo que estos puedan gestionarse mediante las opciones de eliminar paquetes, instalar, desinstalar, reinstalar y actualizar. Además cuenta con las funcionalidades de crear un nuevo paquete, y revertir los cambios realizados en una actualización.

A través del sistema de búsqueda pueden encontrarse los paquetes que se desean gestionar, de los que también es posible conocer el estado, cuál es su última versión y la versión instalada. De cada paquete es posible obtener una descripción, que brinda detalles de los paquetes para facilitar la gestión de los mismos.

Gestionar paquetes

Esta funcionalidad del gestor de paquetes permite gestionar los paquetes del repositorio configurado por el usuario, permitiendo, crear un nuevo paquete, adicionar un paquete al repositorio, eliminar un paquete, hacer búsquedas de paquetes, además de gestionar los repositorios de componentes a los que se accede para poder crear los paquetes de aplicaciones.

Cuando se selecciona la opción Inicio/Herramientas/Panel de control/Gestionar paquetes se muestra la interfaz Gestionar paquetes que permite la gestión de paquetes o aplicaciones, del repositorio configurado por el usuario, ver Figura 1.

Figura 1. Interfaz de Gestionar paquetes.

Crear paquete

Una de las funcionalidades principales de la herramienta es crear nuevos paquetes a partir de la liberación del código estable de un componente desarrollado. Para acceder a esta funcionalidad, en la interfaz principal Gestionar paquetes, ver Figura 1 se selecciona la opción Nuevo y se muestra la interfaz Crear paquete, ver Figura 2.

Figura 2. Interfaz Crear paquete.

En esta interfaz se muestran, en el panel izquierdo los repositorios de componentes gestionados por el usuario, y en el panel derecho los datos del paquete que se desea crear. Para crear un paquete se deben seguir los pasos que se detallan a continuación:

  1. Presionar doble clic sobre el repositorio de componentes deseado en el árbol.
  2. Introducir los datos de inicio de sesión en los repositorios, para listar las etiquetas del componente seleccionado de las cuales no se hayan creado paquetes anteriormente, en la interfaz Autenticación, ver Figura 3.
  3. Desplegar el árbol perteneciente al repositorio seleccionado.
  4. Seleccionar la etiqueta de la cual se desea crear un paquete.
  5. Introducir en la pestaña Paquete los datos solicitados del paquete.
  6. Verificar las dependencias que posee la etiqueta seleccionada que no tienen paquetes creados, en la pestaña Dependencias.
  7. Presionar el botón Aceptar para finalizar la creación del paquete y adicionarlo al repositorio configurado por el usuario, o el botón Aplicar para continuar creando paquetes.

Figura 3. Interfaz de Autenticación.

Gestionar repositorio de componentes

Esta funcionalidad permite adicionar, modificar y eliminar los repositorios a los que el usuario accede para crear los paquetes de aplicaciones. Se accede a Inicio/Herramientas/Panel de control/Gestionar paquetes, se muestra la interfaz principal Gestionar paquetes, se presiona el botón Nuevo y se muestra la interfaz Crear paquete que permite la creación de paquetes nuevos a partir del repositorio que seleccione el usuario, y gestionar los repositorios de componentes, ver Figura 4.

Figura 4. Interfaz Crear paquete.

Adicionar repositorio de componentes

Esta funcionalidad permite adicionar un repositorio de componente al listado de repositorios gestionados por el usuario. Para adicionar un repositorio se deben seguir los pasos siguientes:

  1. Se presiona el botón Adicionar que se muestra en la interfaz Crear paquete, ver Figura 4.
  2. Se introduce la dirección URL del repositorio de componente, en la interfaz Adicionar repositorio, ver Figura 5.
  3. Se presiona el botón Aceptar para finalizar la adición del repositorio al listado, o el botón Aplicar para continuar adicionando repositorios.

 

Figura 5. Interfaz Adicionar repositorio.

Modificar repositorio de componentes

Esta funcionalidad permite modificar un repositorio del listado de repositorios de componentes gestionados por el usuario. Para modificar la información de un repositorio, se deben seguir los siguientes pasos:

  1. Seleccionar el repositorio que se desea modificar del árbol de repositorios que muestra la interfaz Crear paquete ver Figura 4.
  2. Realizar los cambios deseados en la información del repositorio que se muestra en la interfaz Modificar repositorio, ver Figura 6.
  3. Presionar el botón Aceptar para guardar los cambios realizados y actualizar la información del repositorio seleccionado.

 

Figura 6. Interfaz Modificar repositorio.

Eliminar repositorio de componentes

Esta funcionalidad permite eliminar un repositorio del árbol repositorio de componentes gestionado por el usuario, mostrado en la interfaz Crear paquete, ver Figura 4. Para eliminar un repositorio de componentes del árbol se deben seguir los pasos siguientes:

 

  1. Seleccionar el repositorio que se desea eliminar del árbol.
  2. Presionar el botón Eliminar ubicado encima del árbol de repositorios.
  3. Presionar el botón Aceptar del mensaje de confirmación mostrado, ver Figura 7.

Figura 7. Interfaz Eliminar repositorio.

Eliminar paquete

Esta funcionalidad permite eliminar paquetes del repositorio configurado por el usuario. Se accede a Inicio/Herramientas/Panel de control/Gestionar paquetes y se muestra la interfaz principal Gestionar paquetes, ver Figura 1. Se muestra un listado de los paquetes adicionados al repositorio configurado. Para eliminar un paquete del listado se deben seguir los pasos siguientes:

  1. Seleccionar el paquete que se desea eliminar del listado.
  2. Presionar el botón Eliminar ubicado encima del listado mostrado en la interfaz Gestionar paquetes, ver Figura 1.
  3. Presionar el botón Aceptar del mensaje de confirmación mostrado, ver Figura 8.

 

Figura 8. Interfaz Eliminar paquete.

Si se desea eliminar un paquete específico en el listado, se introduce la denominación en el campo de búsqueda que aparece encima del listado de paquetes de la interfaz Gestionar paquetes (Ver Figura 1) y se presiona el botón Buscar. Se mostrará el paquete que coincida con el criterio de búsqueda introducido y el usuario lo podrá eliminar.
