--Desglose de actividades por fecha--

Esta funcionalidad permite desglosar los niveles de una actividad por fecha. Para acceder a esta funcionalidad se selecciona Inicio/Planificación material/Bases para el plan/Desglose de actividades por fecha.
Luego de seleccionada esta funcionalidad, se mostrará en pantalla la interfaz de la misma, donde el usuario podrá realizar todas las acciones a las que tenga acceso definido, ver figura 1. Las operaciones que se pueden realizar con esta funcionalidad están señaladas con números mostrándose el orden y la posición que ocupa cada una de las acciones que se ejecutan.



Figura 1. Interfaz Desglose de actividades por fecha.

Las diferentes opciones que conforman la figura anterior permiten:

  1. Lista de entidades.
  2. Lista de actividades.
  3. Ir a la primera página, mostrando las primeras actividades.
  4. Ir a la página anterior.
  5. Muestra el número de la página donde se encuentra, se puede introducir el número.
  6. Muestra el número máximo de páginas.
  7. Ir a la siguiente página.
  8. Ir a la última página.
  9. Actualizar el listado de actividades.
  10. Limpiar filtro(s). Esta acción limpiará todos los criterios de búsqueda, deshabilitando los filtros realizados. Se puede realizar esta operación seleccionando la combinación de teclas (Alt + L).
  11. Mostrar la cantidad de resultados encontrados.
  12. Permite Exportar los niveles de actividad que están desglosados por fecha.
  13. Mostrar la ayuda.

Luego de seleccionar una entidad de las que se muestran al desglosar el  árbol de entidades y seleccionada una actividad de las listadas en el panel derecho Niveles de actividad se activa la opción (1) que aparece en la figura 2.  Se selecciona dicha opción y se despliega el panel Desglose por fecha como se muestra en la opción (1) de la figura 3.


Figura 2. Interfaz Desglose de actividades por fecha.


Figura 3. Interfaz Adicionar desglose por fecha.

Las opciones que se muestran en la figura anterior permiten:

  1. Mostrar el nombre de la ventana.
  2. Adicionar desglose, ver Adicionar desglose. Esta acción permite adicionar desglose de actividades por fecha. Se puede acceder a esta funcionalidad con las teclas (Alt + I).
  3. Eliminar desglose, esta acción permite eliminar el(los) desglose(s) seleccionado(s), una vez seleccionado(s) el(los) mismo(s) se procede a seleccionar la opción Eliminar de la interfaz. Luego de seleccionada la opción el sistema le mostrará un mensaje de confirmación, se acepta el mensaje y se muestra un mensaje de información sobre el éxito de la operación realizada. De cancelar el mensaje de confirmación, no se ejecuta ninguna acción. Se puede acceder a esta funcionalidad con la tecla (Delete).
  4. Guardar desglose, esta acción permite guardar el(los) desglose(s) realizado(s), una vez realizado el desglose, se procede a seleccionar la opción Guardar de la interfaz. Automáticamente se mostrará un mensaje de información sobre el éxito de la operación realizada, se presiona el botón Aceptar del mensaje y el sistema guarda los datos. Se puede acceder a esta funcionalidad con las teclas (Alt + G).

Adicionar desglose de actividades por fecha
Para adicionar un desglose por fecha se presiona la opción (2) que aparece en la figura 3. El sistema le adicionará automáticamente una fila con el nivel de la actividad sin desglosar, ese valor puede ser modificado por un valor menor que el límite que se muestra en el campo Nivel de actividad en caso deseado. Seguidamente se selecciona la fecha inicio y fin del desglose como se muestra en la figura 4 y se selecciona la opción (4) de la figura 3 para guardar los desgloses realizados. Una vez seleccionado el mismo, el sistema le mostrará un mensaje de confirmación, se acepta el mensaje y se un mensaje de información sobre el éxito de la operación realizada. De presionar la opción Cancelar del mensaje, se cierra el mensaje y no se guarda el desglose efectuado.


Figura 4. Campos de la interfaz desglose por fecha.

Validaciones de los campos:

  • Si se selecciona una actividad que ya tenía desgloses definidos el panel Desglose por fecha se expande automáticamente después de seleccionar la actividad.
  • El valor de la columna nivel puede ser modificado por un valor menor. Si se modifica la columna Nivel con un valor mayor que el nivel límite mostrado en el mismo o en el campo: Nivel de actividad del nivel de actividad seleccionado, y se presiona el botón Guardar el sistema muestra el siguiente mensaje: “No se puede desglosar porque se ha alcanzado el límite máximo.”.
  • Si no se selecciona la fecha de inicio y la fecha fin, y se presione el botón Guardar el sistema no permite guardar los datos y muestra el siguiente mensaje: “Por favor verifique, existen campos con fechas nulas.”. 
  • Si no se introduce un número en el campo nivel el sistema muestra el siguiente mensaje: “Existen campo(s) con valor(es) incorrecto(s) o vacío(s).”.
