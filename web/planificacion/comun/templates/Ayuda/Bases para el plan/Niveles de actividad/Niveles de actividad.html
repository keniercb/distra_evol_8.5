Niveles de actividad

Esta funcionalidad fue diseñada con el objetivo de permitir al usuario asignar Niveles de actividad a las actividades que se prevén realizar como resultado de un proceso productivo, de servicio o de aseguramiento en el año que se planifica. Para acceder a esta funcionalidad se seleccionar Inicio\Planificación material\Bases para el plan\Niveles de actividad.
Una vez seleccionada dicha opción, El sistema le mostrará la interfaz Niveles de actividad,  despliegue el árbol de entidades haciendo clic en el signo Más (+) del panel Entidades y seleccione la entidad donde asignará Niveles de actividad.
Al seleccionar la entidad se mostrarán en la parte derecha de la ventana principal, denominada Niveles de actividad, las actividades aprobadas y que tienen una norma de consumo asociada como se muestra en la figura 1. Las actividades que son generadas por reglas, se mostrarán coloreadas en rojo. Luego de mostradas las actividades se procede a seleccionar la actividad a la que quiere asignar un Nivel de actividad. Se presiona doble clic en el campo Nivel manual y se inserta el número correspondiente al nivel de actividad que quiere asignar a la actividad seleccionada. En caso de que la actividad a la que asigna nivel, tenga establecida una regla, se asignarán además los niveles correspondientes en la columna Nivel automático. Los niveles automáticos no son editables por lo que el usuario no los puede modificar. De igual forma se mostrará en la columna Importe el resultado del cálculo.



Figura 1. Interfaz Niveles de actividad.

Las diferentes opciones que conforman la figura anterior permiten:

  1. Exportar niveles, ver Exportar niveles. Se puede realizar esta acción de manera rápida presionando la combinación de teclas (Alt + E).
  2. Permite asignar niveles de actividad, una vez introducido los datos en los campos Nivel manual, NP (Nivel de producción) y Ajuste se debe presionar el botón Guardar y el sistema mostrará un mensaje de información notificando que los niveles de actividad se guardaron satisfactoriamente, se acepta el mensaje de información y el sistema suma los valores del Nivel manual y NP (nivel de producción), poniendo automáticamente dicha suma en el campo Nivel de actividad. Se puede realizar esta acción de manera rápida presionando la combinación de teclas (Alt + G).
  3. Realizar acciones en el Almacén de datos. Se pueden realizar dos acciones Cierre y Actualizar, en ambos casos el sistema mostrará un mensaje de información notificando que se realizó la operación con existo.
  4. Permite cambiar de Ejercicio. Inicialmente todas las operaciones realizadas en la interfaz, se efectuarán sobre el ejercicio actual, de querer asignar niveles de actividad en un ejercicio diferente al actual, se procede a desglosar dicho campo y seleccionar uno de los ejercicios listados. Automáticamente el sistema recargará el panel Niveles de actividad con cada una de las actividades correspondientes al ejercicio seleccionado.
  5. Mostrar ayuda de la funcionalidad. Se puede acceder a esta funcionalidad de manera rápida seleccionando la combinación de las teclas (Alt + H).
  6. Aprobar todos los nivel, para efectuar esta acción se debe seleccionar clic derecho encima de la entidad a la cual se le desea aprobar el(los) nivel de actividad y seleccionar la opción Aprobar todos. Una vez seleccionada la misma, el sistema le mostrará un mensaje de confirmación, se acepta el mensaje y le mostrará un mensaje de información sobre el éxito de la operación realizada, se acepta el mensaje de información y se aprueba(n) el(los) nivel(es) de actividad de la entidad seleccionada. Si se opta por la opción Cancelar, el sistema cancela la acción y no permite aprobar las actividades. Se puede acceder a esta funcionalidad de manera rápida con la combinación de las teclas (Ctrl + Alt + Q). Esta opción solo aprobará aquellas actividades que presenten nivel de actividad definido. En caso que desee aprobar una o varias actividades de forma independiente, se puede apoyar en la opción Aprobar nivel, que le aparecerá al presionar clic derecho (secundario) sobre una actividad con nivel de actividad asignado, dicha funcionalidad solo se habilitará si selecciona al menos una actividad que presente nivel de actividad definido.
  7. Desaprobar todos los nivel, para efectuar esta acción se debe seleccionar clic derecho encima de la entidad a la cual se le desea desaprobar el(los) nivel de actividad y seleccionar la opción Desaprobar todos. Una vez seleccionada la misma, el sistema le mostrará un mensaje de confirmación, se acepta el mensaje y le mostrará un mensaje de información sobre el éxito de la operación realizada, se acepta el mensaje de información y se desaprueba(n) el(los) nivel(es) de actividad de la entidad seleccionada. Si se opta por la opción Cancelar, el sistema cancela la acción y no permite desaprobar las actividades. Se puede acceder a esta funcionalidad de manera rápida con la combinación de las teclas (Ctrl + Alt + W). Esta opción solo desaprobará aquellas actividades que presenten nivel de actividad definido. En caso que desee desaprobar una o varias actividades de forma independiente, se puede apoyar en la opción Desaprobar nivel, que le aparecerá al presionar clic derecho (secundario) sobre una actividad, dicha funcionalidad solo se habilitará si selecciona al menos una actividad que presente estado Aprobado.
  8. Mostrar el listado de actividades de la entidad seleccionada.
  9. Ir a la primera página, mostrando las primeras actividades.
  10. Ir a la página anterior.
  11. Muestra el número de la página donde se encuentra, se puede introducir el número.
  12. Muestra el número máximo de páginas.
  13. Ir a la siguiente página.
  14. Ir a la última página.
  15. Actualizar el listado de existencias.
  16. Limpiar filtro(s). Esta acción limpiará todos los criterios de búsqueda, deshabilitando los filtros realizados. Se puede realizar esta operación seleccionando la combinación de teclas (Alt + L).
  17. Muestra la cantidad de elementos a mostrar por páginas. Este campo es seleccionable.
  18. Mostrar la cantidad de resultados encontrados.
Exportar niveles

Esta funcionalidad permite exportar las actividades de una determinada entidad, para exportar los mismos se procederá de igual forma como se explica en el listado de opciones de la siguiente figura.


Figura 2. Abriendo niveles.xls.

Las diferentes opciones que conforman la figura anterior permiten:

  1. Abrir un documento con las actividades pertenecientes a la entidad seleccionada.
  2. Seleccionar formato en que desea guardar o visualizar el documento.
  3. Guardar archivo en la carpeta Descargas.
  4. Ejecutar las opciones (1) o (3) sin mostrar la ventana cada vez que se invoque a la funcionalidad.
  5. Ejecutar la acción según la opción seleccionada.
  6. Cancelar las acciones y salir de la interfaz sin realizar ninguna operación.

Nota: para ejecutar la funcionalidad se debe desglosar el árbol de entidades y seleccionar una entidad de las que se listan, luego de seleccionada la misma se recargará automáticamente el panel derecho Nivel de actividad con cada una de las actividades asociadas a la entidad seleccionada, activando así la opción Exportar.

Buscar nivel de actividad

Esta funcionalidad permite efectuar una búsqueda mediante filtrado en las columnas. Para efectuar la misma debe estar en el panel Niveles de actividades, ver figura 1. Una vez que accedió a esta se presiona clic en el botón “” que aparece en la parte derecha de cada columna.  Luego de presionado el mismo, se procede a desplegar la columna y se ofrece la posibilidad de realizar búsqueda mediante filtrado. Se introduce o selecciona el criterio de filtrado según la información que brinde la columna seleccionada. Inmediatamente se presiona la tecla Enter y el sistema le mostrará en la interfaz los niveles de actividad según el criterio de filtrado seleccionado. En caso de que no existan datos a mostrar para el criterio de filtrado seleccionado el sistema lo notificará mostrando el mensaje de información: “No existen datos que se correspondan con el criterio de búsqueda especificados.”.
