--Tipo de modelo--

En esta funcionalidad se gestionan los tipos de modelos los cuales son imprescindibles para crear los Planes. Para llegar a esta funcionalidad se puede acceder a través de la opción Inicio/Planificación material/Configuraciones/Tipo de modelo.
Una vez seleccionada la funcionalidad, aparecerá en pantalla la interfaz de la misma, donde el usuario autenticado podrá realizar las acciones que desee, en correspondencia con el acceso que tenga definido. Al acceder a la interfaz de Tipo de modelo, ver figura 1, se muestran dos paneles (superior e inferior), en el panel superior se muestra el listado de los tipos de modelos registrados en el sistema y seleccionando un tipo modelo, mediante un clic encima del mismo, se le mostrará en el panel inferior las columnas que posee el tipo de modelo seleccionado.


Figura 1. Interfaz y acciones de la funcionalidad Tipo de modelo.

Las diferentes opciones que conforman la Figura anterior permiten:

  1. Adicionar tipo de modelo, ver Adicionar tipos de modelo , esta acción permite adicionar tipos de modelo, para ejecutarla el sistema le mostrará la interfaz “Adicionar tipo de modelo”, cuando se presione el botón Aceptar o Aplicar de dicha interfaz el sistema mostrará un mensaje de información notificando que se adicionó el tipo de modelo. Se puede acceder a esta funcionalidad con las teclas (Alt + I).
  2. Modificar un tipo de modelo previamente seleccionado en el listado. Una vez seleccionado el tipo de modelo y presionada la opción Modificar de la interfaz, el sistema le mostrará la interfaz con los datos cargados, posibilitando que se modifiquen los datos que se requieran. Se puede acceder a esta funcionalidad seleccionando el tipo de modelo y oprimiendo las teclas (Alt + M). Si al modificar el tipo de modelo se introduce uno que ya existe, el sistema le mostrará un mensaje de error. La opción Modificar se habilitará después de seleccionar un tipo de modelo que no esté en uso y se encuentre en estado desaprobado y la validación de cada uno de los campos de la interfaz será muy similar al descrito en el Adicionar tipo de modelo.
  3. Eliminar un tipo de modelo previamente seleccionado en el listado. Esta acción permite eliminar el(los) tipo(s) de modelo(s) deseado(s), una vez seleccionado(s) se procede a seleccionar la opción Eliminar de la interfaz, automáticamente se mostrará un mensaje de confirmación, que se puede Aceptar o Cancelar según sea el caso, de presionar la opción Aceptar el sistema le mostrará un mensaje de información sobre el éxito de la operación realizada, quedando eliminado(s) el(los) tipo(s) de modelo(s) seleccionado(s), si cancela el mensaje de confirmación, el sistema permanece en la interfaz principal y no elimina el(los) tipo(s) de modelo(s). Se puede realizar esta operación seleccionando el tipo de modelo en el listado y oprimiendo la tecla (Delete). Se debe tener en cuenta las siguientes validaciones al realizar esta acción:
  • La opción Eliminar se habilitará después de seleccionar un tipo de modelo que no esté en uso y en estado desaprobado.
  1. Activar un tipo de modelo previamente seleccionado en el listado. Esta acción permite activar el(los) tipo(s) de modelo(s) deseado(s), una vez seleccionado(s) se procede a seleccionar la opción Activar de la interfaz, automáticamente el sistema le mostrará un mensaje de confirmación, que se puede Aceptar o Cancelar según sea el caso, de presionar la opción Aceptar el sistema le mostrará un mensaje de información sobre el éxito de la operación realizada, quedando activado(s) el(los) tipo(s) de modelo(s) seleccionado(s), si cancela el mensaje de confirmación, el sistema permanece en la interfaz principal y no se activa(n) el(los) tipo(s) de modelo(s). Se puede acceder a esta operación seleccionando el tipo de modelo en el listado y oprimiendo la tecla (Alt + T). Para activar tipos de modelos debe tener en cuenta las siguientes restricciones:
  • Si el tipo de modelo se encuentra en estado de activación (Activado), no será posible volver a activarlo.
  • Si el tipo de modelo se encuentra en estado de aprobación (Aprobado), no será posible activarlo.
  1. Desactivar un tipo de modelo previamente seleccionado en el listado. Esta acción permite desactivar el(los) tipo(s) de modelo(s) deseado(s), una vez seleccionado(s) se procede a seleccionar la opción Desactivar de la interfaz, automáticamente el sistema le mostrará un mensaje de confirmación, que se puede Aceptar o Cancelar según sea el caso, de presionar la opción Aceptar el sistema le mostrará un mensaje de información sobre el éxito de la operación realizada, quedando desactivado(s) el(los) tipo(s) de modelo(s) seleccionado(s), si cancela el mensaje de confirmación, el sistema permanece en la interfaz principal y no se desactivará(n) el(los) tipo(s) de modelo(s). Se puede realizar esta operación seleccionando el tipo de modelo en el listado y oprimiendo la tecla (Alt + F). Para desactivar tipos de modelos debe tener en cuenta las siguientes restricciones:
  • Si el tipo de modelo se encuentra en estado de activación (Desactivado), no será posible volver a desactivarlo.
  • Si el tipo de modelo se encuentra en estado de aprobación (Aprobado), no será posible desactivarlo.
  1. Aprobar un tipo de modelo previamente seleccionado. Esta acción permite aprobar el(los) tipo(s) de modelo(s) deseado(s), una vez seleccionado(s) se procede a seleccionar la opción Aprobar de la interfaz, automáticamente el sistema le mostrará un mensaje de confirmación, que se puede Aceptar o Cancelar según sea el caso, de presionar la opción Aceptar el sistema le mostrará un mensaje de información sobre el éxito de la operación realizada, quedando aprobado(s) el(los) tipo(s) de modelo(s) seleccionado(s), si cancela el mensaje de confirmación, el sistema permanece en la interfaz principal y no se aprobará(n) el(los) tipo(s) de modelo(s). Se puede realizar esta operación seleccionando el tipo de modelo en el listado y oprimiendo la tecla (Alt + Q). Para aprobar tipos de modelos debe tener en cuenta las siguientes restricciones:
  • Si el tipo de modelo se encuentra en estado de aprobación (Aprobado), no será posible volverlo a aprobar.
  • Si el tipo de modelo se encuentra en Uso, implica que ya se encuentra en estado de aprobación (Aprobado), cuestión que el sistema tendrá en cuenta y deshabilitará  la funcionalidad de Aprobar.
  1. Desaprobar un tipo de modelo previamente seleccionado. Esta acción permite desaprobar el(los) tipo(s) de modelo(s) deseado(s), una vez seleccionado(s) se procede a seleccionar la opción Desaprobar de la interfaz, automáticamente el sistema le mostrará un mensaje de confirmación, que se puede Aceptar o Cancelar según sea el caso, de presionar la opción Aceptar el sistema le mostrará un mensaje de información sobre el éxito de la operación realizada, quedando desaprobado(s) el(los) tipo(s) de modelo(s) seleccionado(s), si cancela el mensaje de confirmación, el sistema permanece en la interfaz principal y no se desaprobará(n) el(los) tipo(s) de modelo(s). Se puede realizar esta operación seleccionando el tipo de modelo en el listado y oprimiendo la tecla (Alt + W). Para desaprobar tipos de modelos debe tener en cuenta las siguientes restricciones:
  • Si el tipo de modelo se encuentra en estado de aprobación (Desaprobado), no será posible volverlo a desaprobar.
  • Si el tipo de modelo se encuentra en Uso, no se podrá desaprobar y el sistema le notificará mostrándole un mensaje de error.

  2. Se muestra el listado de tipos de modelos.
  3. Ir a la primera página, mostrando los primeros tipos de modelo.
  4. Ir a la página anterior.

  6. Muestra el número máximo de páginas.
  7.  Ir a la siguiente página.
  8. Ir a la última página.
  9. Actualizar el listado de tipos de modelos.
  10. Limpiar filtro(s). Esta acción limpiará todos los criterios de búsqueda, deshabilitando los filtros realizados. Se puede realizar esta operación seleccionando la combinación de teclas (Alt + L).
  11. Mostrar la cantidad de resultados encontrados.
  12. Si desea visualizar o esconder el panel inferior lo puede hacer presionando la opción (19).
  13. Adicionar columnas a un tipo de modelo, ver Acápite Adicionar columna a un tipo de modelo, esta acción permite adicionar columnas al tipo de modelo. Se puede realizar esta operación seleccionando el tipo de modelo en el listado y oprimiendo la tecla (Ctrl + Alt + C).
  14. Eliminar columnas a un tipo de modelo, esta acción permite eliminar columnas al tipo de modelo. Para ejecutar dicha acción se debe seleccionar un tipo de modelo que se encuentre en estado de Aprobación (Desaprobado) y En uso (No), automáticamente se listará en el panel inferior “Columnas del tipo de modelo” cada una de las columnas que han sido adicionadas al tipo de modelo seleccionado, luego de listadas las mismas se procede a seleccionar la columna que desea eliminar y se selecciona la opción Eliminar de dicho panel, inmediatamente el sistema le mostrará un mensaje de confirmación de la operación, que se puede Aceptar o Cancelar según sea el caso, de presionar la opción Aceptar el sistema le mostrará un mensaje de información sobre el éxito de la operación realizada, quedando eliminada la columna del tipo de modelo seleccionada, y para finalizar debe aceptar este mensaje. De cancelar el mensaje de confirmación el sistema permanece en la interfaz principal y no eliminará la columna del tipo de modelo seleccionado. Se puede realizar esta operación seleccionando el tipo de modelo en el listado y oprimiendo la tecla (Delete).
  15. Se muestra el listado de las columnas pertenecientes al tipo de modelo seleccionado.
Adicionar tipo de modelo  
Se presiona el botón Adicionar que se encuentra en la barra de acciones de la interfaz, ver figura 1. Inmediatamente aparecerá una ventana donde se podrán especificar los datos relacionados con el tipo de modelo que se desea adicionar, ver Figura 2.


Figura 2. Interfaz Adicionar tipo de modelo.

Las opciones de la Figura anterior permiten:

  1. Introducir el código del tipo de modelo que desea insertar.
  2. Introducir la denominación del tipo de modelo que desea insertar.
  3. Introducir una breve descripción del tipo de modelo a insertar. Este dato no es obligatorio.
  4. Cancelar las acciones y salir de la interfaz sin guardar los datos.
  5. Guardar los datos y limpiar los campos de la interfaz, permitiendo adicionar otro tipo de modelo.
  6. Adicionar los datos del tipo de modelo al listado y cerrar la interfaz.

Validación de los campos:

  • Los campos Código y Denominación son obligatorios, en caso de dejar estos campos vacíos el sistema le notificará subrayándolo en rojo y mostrando un mensaje de error, si se presiona el botón Aceptar o Aplicar de la interfaz el sistema mostrará un mensaje de información notificando que existen campos obligatorios en blanco.
  • No se permite adicionar un Tipo de modelo con un mismo código. Si esto ocurre el sistema debe mostrar un mensaje de error.
  • El campo código acepta solo números enteros positivos con una longitud de hasta 19 dígitos. En caso de introducir algún carácter extraño el sistema le notificará mostrando un mensaje de error, si sobrepasa la cantidad establecida mostrará el mensaje de error en el mismo campo.
  • El campo denominación acepta caracteres alfanuméricos hasta 255 caracteres, en caso de introducir algún caracteres especial y presionar el botón Aceptar o Aplicar  se debe mostrar un mensaje de información notificando que existen campo(s) con valor(es) incorrecto(s) o vacío(s). De sobrepasar la cantidad establecida el sistema le notificará subrayando el campo en rojo y mostrando un mensaje de error, al pasar el cursor del mouse por encima del campo subrayado, así como al escribir algún  caracter especial no permitido notificará subrayando el campo en rojo y mostrando un mensaje.
  • El campo descripción acepta caracteres alfanuméricos y caracteres especiales sin límites, puede ser vacío.
  • Cuando se adicione un tipo de modelo, este se adicionara automáticamente con estado activado.
Adicionar columna a un tipo de modelo 

Lo primero que debe hacer es seleccionar el tipo de modelo al cual le desea adicionar las columnas. Para ello debe tener presente que el tipo de modelo seleccionado no debe de estar en estado de aprobación (Aprobado), ni en Uso, esta última condición implica también la primera, cuestión que el sistema tendrá en cuenta y le deshabilitará las funcionalidades referentes a la interfaz Columnas del tipo de modelo.
Una vez que seleccione el tipo de modelo, debe optar por la funcionalidad Adicionar referente a la interfaz Columnas del tipo de modelo, ver figura 1. Seguidamente el sistema le mostrará una interfaz para adicionar columnas al tipo de modelo seleccionado anteriormente, ver figura 3.



Figura 3. Adicionar columnas a un tipo de modelo.

Las opciones de la Figura anterior permiten:

  1. Seleccionar la denominación de la columna que desea adicionar al tipo de modelo seleccionado.
  2. Seleccionar el tipo de dato que presentará la columna que desea adicionar al tipo de modelo seleccionado. Si selecciona en el campo Tipo de dato: “Cadena de caracteres” se habilitará el nuevo campo “Expresión regular” para seleccionar el tipo de dato que almacenará la Cadena de caracteres como se muestra en la figura 4. Si selecciona en el campo Tipo de dato: “Nomenclador” se habilitará el nuevo campo “Conceptos” para seleccionar el concepto de nomenclador que almacenará el Nomenclador como se muestra en la figura 5.
  3. Cancelar las acciones y salir de la interfaz sin guardar los datos.
  4. Guardar los datos y limpiar los campos de la interfaz, permitiendo adicionar otra columna al tipo de modelo seleccionado.
  5. Adicionar los datos de la columna al listado y cerrar la interfaz.


Figura 4. Selección del Tipo de dato: “Cadena de caracteres”.


Figura 5. Selección del Tipo de dato: “Nomenclador”.

Validación de los campos:

  • Todos los campos de la interfaz son obligatorios, en caso de no seleccionar alguno y presionar el botón Aceptar o Aplicar el sistema se lo notificará mostrándole el mensaje de información.

Buscar tipos de modelos

Esta funcionalidad permite efectuar una búsqueda mediante filtrado en las columnas. Para efectuar la misma debe estar en la interfaz principal, ver figura 1, una vez que accedió a esta se presiona clic en el botón “” que aparece en la parte derecha de cada columna.  Luego de presionado el mismo, se procede a desplegar la columna y se ofrece la posibilidad de realizar búsqueda mediante filtrado. Se introduce o selecciona el criterio de filtrado según la información que brinde la columna seleccionada. Inmediatamente se presiona la tecla Enter y el sistema le mostrará en la interfaz los tipos de modelo según el criterio de filtrado seleccionado. En caso de que no existan tipos de modelos a mostrar para el criterio de filtrado seleccionado el sistema lo notificará mostrando el mensaje de información: “No existen datos que se correspondan con el criterio de búsqueda especificados.”, ver figura 6 .
