--Cálculo de niveles--

Para acceder a esta funcionalidad se debe seleccionar la opción Inicio/Planificación material/Cálculo de niveles/Cálculo de niveles. Una vez accedida a la misma el sistema le mostrará en pantalla la interfaz de la misma, donde el usuario podrá realizar todas las acciones a las que tenga acceso, ver figura 1. Las operaciones que se pueden realizar con esta funcionalidad están señaladas con números mostrándose el orden y la posición que ocupa cada una de las acciones que se ejecutan.

 

Nota: para activar el panel entidades, se debe seleccionar un Componente, opción (6) de la figura 1. Automáticamente el sistema activará el panel Entidades y las diferentes acciones que permite realizar el sistema.

Figura 1. Interfaz Cálculo de niveles.

Las diferentes opciones que conforman la Figura anterior permiten:

  1. Gestionar tipo de balance, el sistema mostrará una interfaz permitiendo Adicionar, Modificar y Eliminar tipo de balance, Ver Figura 2 y 3. Se puede acceder a esta funcionalidad de manera rápida con la combinación de las teclas (Ctrl + Alt + T).
  2. Gestionar subtipo de balance, el sistema mostrará una interfaz permitiendo Adicionar, Modificar, Eliminar y Buscar un subtipo de balance, ver Figura 4 y 5. Se puede acceder a esta funcionalidad de manera rápida con la combinación de las teclas (Ctrl + Alt + S).
  3. Gestionar balance, el sistema mostrará una interfaz permitiendo Adicionar, Modificar y Eliminar balance, ver Figura 6 y 7. Se puede acceder a esta funcionalidad de manera rápida con la combinación de las teclas (Ctrl + Alt + B).
  4. Asociar balances. Esta funcionalidad le permitirá efectuar la asociación de balances. Para ejecutar dicha acción, se deben haber listado los balances en el panel derecho Balances, una vez listados los mismos, se procede a seleccionar un balance y en dependencia de su estado si está asociado o no, se activará el botón Asociar se presiona clic encima del botón Asociar y el sistema le mostrará un mensaje de información notificando que la operación se ha realizado satisfactoriamente. Se puede acceder a esta funcionalidad de manera rápida con la combinación de las teclas (Alt + K).
  5. Desasociar balances, una vez listado los balances en la interfaz Balances, seleccione un balance y en dependencia de su estado si está asociado o no, se activará el botón Desasociar, se presiona clic encima del botón Desasociar y el sistema mostrará un mensaje informando que la operación se ha realizado correctamente.
  6. Seleccionar el componente.
  7. Guardar datos del balance, se debe introducir datos en el campo Cantidad y presionar el botón Guardar, el sistema mostrará un mensaje de información notificando que se realizó con éxito la operación. Este campo solo acepta números.
  8. Exportar balance.
  9. Mostrar la ayuda de la funcionalidad. Se puede acceder a esta funcionalidad de manera rápida con la combinación de las teclas (Alt + H).
  10. Filtrar entidades por un criterio de búsqueda específico.
  11. Seleccionar el tipo de balance.
  12. Seleccionar el subtipo de balance.
  13. Marcar si desea marcar todos los balances.
  14. Listar las entidades.
  15. Listar los balances.
  16. Mostrar el total parcial de los balances.
  17. Mostrar el total general de los balances.

Gestionar tipo de balance

Para gestionar tipo de balance debe seleccionar la opción (1) de la Figura 1, el sistema mostrará la siguiente interfaz, ver Figura 2.

Figura 2. Interfaz Gestionar tipo de balance.

Las diferentes opciones que conforman la figura anterior permiten:

1. Adicionar tipo de balance, ver Adicionar tipo de balance. Una vez seleccionada dicha opción el sistema le mostrará una interfaz permitiendo adicionar los datos del tipo de balance que quiere adicionar. Se puede acceder a esta funcionalidad de manera rápida con la combinación de las teclas (Alt + I).
2. Modificar tipo de balance, esta acción es muy similar a la acción de Adicionar tipo de balance. El botón Modificar solo se activará cuando se seleccione al menos un tipo de balance de la lista. Se puede acceder a esta funcionalidad de manera rápida seleccionando el tipo de balance y presionando la combinación de las teclas (Alt + M). La validación de cada uno de los  campos es muy similar al descrito en el Adicionar tipo de balance.
3. Eliminar tipo de balance, el botón Eliminar solo se activará cuando se seleccione al menos un tipo de balance de la lista. Una vez seleccionado al menos un tipo de balance  y presionada la opción Eliminar de la interfaz, el sistema le mostrará un mensaje de confirmación confirmando que si está seguro que quiere eliminar el tipo de balance seleccionado, si presiona el botón Aceptar el sistema le mostrará un mensaje de información notificando que se realizó la operación con éxito, si presiona el botón Cancelar el sistema cancela la acción y no elimina el tipo de balance seleccionado. Se puede acceder de manera rápida a esta acción seleccionando el tipo de balance que quiere eliminar y presionando la tecla (Delete).
4. Listar los tipos de balances que están adicionados.

Adicionar tipo de balance

Para ejecutar esta funcionalidad se debe presionar el botón Adicionar, opción (1) de la figura 2. Una vez presionada dicha opción el sistema le mostrará la siguiente interfaz, ver figura 3.

Figura 3. Interfaz Adicionar tipo de balance.

Las diferentes opciones que conforman la figura anterior permiten:
1. Introducir la denominación del tipo de balance.
2. Introducir una breve descripción del tipo de balance.
3. Cancelar las acciones y salir de la interfaz sin guardar los datos.
4. Guardar los datos y limpiar los campos de la interfaz, permitiendo adicionar otro tipo de balance.
5. Adicionar los datos del tipo de balance al listado y cerrar la interfaz.

Nota: Para adicionar un tipo de balance se deben tener en cuenta las siguientes validaciones:

  • No se puede adicionar un tipo de balance con una misma denominación, si esto ocurre el sistema le mostrará un mensaje de error.
  • El campo denominación solo acepta letras hasta 255 caracteres, si sobrepasa la cantidad establecida el sistema debe mostrar un mensaje de error en el mismo campo.
  • El campo descripción solo acepta caracteres alfanuméricos y todos los caracteres especiales sin límite. Este no debe ser vacío.

    Buscar balance

    Esta funcionalidad permite efectuar una búsqueda mediante filtrado en las columnas. Para efectuar la misma debe estar en la interfaz principal, ver figura 1. Una vez que accedió a la misma se presiona clic en el botón “” que aparece en la parte derecha de cada columna.  Luego de presionado el mismo, se procede a desplegar la columna y se ofrece la posibilidad de realizar búsqueda mediante filtrado. Se introduce o selecciona el criterio de filtrado según la información que brinde la columna seleccionada. Inmediatamente se presiona la tecla Enter y el sistema le mostrará en la interfaz los balances según el criterio de filtrado seleccionado. En caso de que no existan balances a mostrar para el criterio de filtrado seleccionado el sistema lo notificará mostrando el mensaje de información: “No existen datos que se correspondan con el criterio de búsqueda especificados.”.

    Limpiar criterio de búsquedas
    Una vez realizada la búsqueda mediante el filtrado de columnas, para limpiar los criterios de filtrado introducidos debe de presionar la opción Limpiar que aparece ubicada en la parte central inferior de la interfaz. Esta opción limpiará todos los criterios de búsqueda, deshabilitando los filtros realizados y recargando todos los indicadores en la interfaz.
