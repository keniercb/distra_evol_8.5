--Estados de la información--

Esta funcionalidad permite gestionar los tipos de documentos y los estados de aprobación de los documentos o elementos de la planificación. Para acceder a estas funcionalidades el usuario debe estar autenticado y debe seleccionar la ruta: Inicio/Configuración general/Flujo de Trabajo/Estados de la información. La interfaz Estados de la información muestra las operaciones que pueden hacerse con los estados de la información, ver Figura 1.


Figura 1. Interfaz y acciones de la funcionalidad Estados de la información.

Las diferentes opciones que conforman la figura anterior permiten:

  1. Adicionar estado, ver Adiconar estado, esta acción permite adicionar estados, cuando se presione el botón Aceptar o Aplicar de la interfaz el sistema mostrará un mensaje de información notificando que se adicionó el estado. Se puede acceder a esta funcionalidad con las teclas (Alt + I).
  2. Modificar un estado previamente seleccionada en el listado. Se mostrará la interfaz con los datos cargados, posibilitando que se modifiquen los que se requieran. Se puede acceder a esta funcionalidad seleccionando un estado y oprimiendo las teclas (Alt + M). Si al modificar el estado se introduce uno que ya existe, el sistema mostrará un mensaje de erro. La validación del campo de la interfaz será muy similar al descrito en el Adicionar estado.
  3. Eliminar un estado previamente seleccionada en el listado. Esta acción permite eliminar el(los) estado(s) deseado(s), una vez seleccionado(s) el(los) mismo(s) se procede a seleccionar la opción Eliminar de la interfaz, automáticamente se mostrará un mensaje de confirmación, que se puede Aceptar o Cancelar según sea el caso, de presionar la opción Aceptar el sistema le mostrará un mensaje de información sobre el éxito de la operación realizada, quedando eliminado(s) el(los) estado(s) seleccionado(s), si cancela el mensaje de confirmación, el sistema permanece en la interfaz principal y no elimina el(los) estado(s). Se puede realizar esta operación seleccionando el estado en el listado y oprimiendo la tecla (Del). Si se selecciona un estado que esté asociado a un tipo de documento, no se podrá eliminar hasta que dicha asociación se elimine. El sistema activará la opción Eliminar de la interfaz cuando seleccione un estado.
  4. Asociar estados, ver Asociar estados.
  5. Buscar un estado, esta acción permite buscar un estado. Para ejecutar esta acción debe introducirse datos en el campo Denominación y una vez especificados los datos, se selecciona el botón Buscar. Se debe tener en cuenta las siguientes validaciones al realizar esta acción:
  • En caso de no introducir un dato para la búsqueda y seleccionar la opción Buscar se mostrara un mensaje de error.
  • En caso que no existan datos que cumplan con el criterio de búsqueda especificado, se muestra el siguiente mensaje de información: “No existen datos que se correspondan con los criterios de búsqueda especificados.”.
  1. Limpiar los filtros de las columnas. Se puede acceder a esta funcionalidad seleccionando la combinación  de teclas (Alt + L).
  2. Actualizar el listado de estados. Se puede realizar esta acción con la combinación de las letras (Ctrl + Alt + Z).
  3. Mostrar el listado de estados.
  4. Ir a la primera página, mostrando los primeros estados.
  5. Ir a la página anterior.
  6. Mostrar el número de la página donde se encuentra, se puede introducir el número de la página a la que se desea ir.
  7. Mostrar el número máximo de páginas.
  8. Ir a la siguiente página.
  9. Ir a la última página.
  10. Actualizar la lista de registro de estado de los documentos.
  11. Mostrar la cantidad de resultados encontrados.

 Adicionar estado
Se presiona el botón Adicionar de la interfaz, ver opción (1) de la Figura 1. Inmediatamente aparecerá una ventana donde se podrán especificar los datos relacionados con el estado que se desea adicionar, ver Figura 2.


Figura 2. Operación Adicionar estado.

Las opciones de la figura anterior permiten:

  1. Introducir la denominación del estado que desea insertar.
  2. Cancelar las acciones y salir de la interfaz sin guardar los datos.
  3. Guardar los datos y limpiar los campos de la interfaz, permitiendo adicionar otro estado.
  4. Adicionar los datos del estado al listado y cerrar la interfaz.

Validación de los campos:

  • El campo Denominación es obligatorio, en caso de dejar este campo vacío el sistema le notificará el error, subrayando el campo en rojo y mostrando un mensaje de error, al pasar el cursor del mouse por encima del campo subrayado, y el mensaje de error “Por favor  verifique que el campo está vacío”, en caso que haya presionado el botón Aceptar o Aplicar de la interfaz. El campo acepta los caracteres especiales (“%#@!*() _;:,?-.). Al escribir otro tipo de carácter no permitido notificará subrayando el campo en rojo y mostrando el mensaje. También debe tener en cuenta que no podrá adicionar un estado con la misma denominación que otra, de suceder esto el sistema le notificará mostrándole un mensaje de error.

Asociar Estados
El sistema permite que el usuario le asocie estados a los tipos de documentos. Para que se habilite la opción Asociar estados es necesario que no esté seleccionado ningún estado. Una vez que este habilitada la opción Asociar estados se selecciona el tipo de documento deseado por el usuario y se mostrará una interfaz, ver Figura 3.


Figura 3. Interfaz Asociar estados.

Las diferentes opciones que conforman la figura anterior permiten:

  1. Mostrar el listado de estados sin asociar.
  2. Asociar servicios al contrato, se mostrarán los estados registrados en el sistema pero que no han sido asociados al tipo de documento sobre el que se está trabajando. Para asociarlo seleccione un estado y selecciona la opción 2 de la Figura 3, que se encuentra en el centro del panel. Como resultado se mostrará un mensaje de información indicando que la operación fue realizada satisfactoriamente. La opción (2) de la Figura 3 no se activará hasta que no se haya seleccionado un elemento de la lista de Estados sin asociar.
  3. Desasociar servicios al contrato, cuando no desee mantener asociado al tipo de documento con el cual se esté trabajando en un estado determinado, seleccione en el panel Estados asociados el que desea desasociar, y seleccione la opción (3) de la Figura 3, que se encuentra en el centro del panel. Como resultado se mostrará un mensaje de información  indicando que la operación fue satisfactoria. En caso que un estado que se desea desasociar a un tipo de documento determinado esté siendo utilizado en alguna transición creada, se mostrará un mensaje de error informando que no se pudo realizar la operación satisfactoriamente. La opción (3) de la Figura 3 no se activará hasta que no se haya seleccionado un elemento de la lista Estados asociados.
  4. Seleccionar el estado como estado inicial para establecer el estado predeterminado que tomará un documento cuando se adiciona. El sistema mostrará un mensaje de confirmación para asegurarse de que realmente desea realizar la operación. En caso que se presione el botón Cancelar, no se realizará la operación deseada, en cambio, si presiona el botón Aceptar, se mostrará un mensaje de información notificando que ha sido exitosa la operación.
  5. Eliminar la selección como estado inicial, el sistema mostrará un mensaje de confirmación para asegurarse de que realmente desea realizar la operación. En caso que se presione el botón Cancelar, no se realizará la operación deseada, en cambio, si presiona el botón Aceptar, se mostrará un mensaje de información notificando que ha sido exitosa la operación.
  6. Establecer  el estado a partir del cual se generarán notificaciones cuando un tipo de documento es modificado. El sistema mostrará un mensaje de confirmación para asegurarse de que realmente desea realizar la operación. En caso que se presione el botón Cancelar, no se realizará la operación deseada, en cambio, si presiona el botón Aceptar, se mostrará un mensaje informando que ha sido exitosa la operación.
  7. Eliminar la selección como estado generador de  notificaciones, el sistema pedirá la confirmación al usuario para realizar dicha operación y finalmente realizará la operación si presiona el botón Aceptar.
  8. Establecer restricciones a los subordinados sobre los estados heredados. El sistema mostrará la interfaz que se muestra en la Figura 4. En el panel Subordinados restringidos se muestran los subordinados que podrán usar este estado como estado inicial o final en dependencia de lo que el usuario desee. En caso que se presione el botón Cancelar, no se realizará la operación deseada, en cambio, si presiona el botón Aceptar, se mostrará un mensaje de información notificando que ha sido exitosa la operación, ver Figura 4.
